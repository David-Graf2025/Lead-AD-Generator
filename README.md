# Lead & Ad Generator Skills

This repository contains two Codex skills:

- `lead-generator` — researches small product brands and builds outreach-ready lead lists.
- `ad-generator` — creates brand-informed prompts for premium static advertisements.

Each skill lives in its own directory and includes its `SKILL.md` instructions. The ad generator also includes its reusable ad templates.

## Installation

Copy either skill directory into your Codex skills directory, then restart or reload Codex so the skill is discovered.
